# Cinzel Decorative

Unmodified Regular font by Natanael Gama, downloaded from the official
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/cinzeldecorative).
Redistributed under the included SIL Open Font License (`OFL.txt`).
Used for Living Migration research titles and root names; body text retains the
normal UI font for readability.
